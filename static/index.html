The user needs the Standard CCM Admin Users role plus access to Standard SERVICEABILITY / Real-Time and Trace Collection (the Standard RealtimeAndTraceCollection role). Read-only: the app only lists and downloads.

How CUCM delivers CDR files

CDR on Demand cannot return file contents over SOAP: CUCM connects out to an SFTP server and uploads the file. CUCM always connects to port 22. The built-in receiver needs rights to listen there (or a port forward 22 → listen port).

SDL trace collection

SDL tracing must be on for Cisco CallManager (Trace Configuration → Debug level ≥ Detailed, with "SIP Call Processing Trace" enabled), otherwise no SIP messages are written.
